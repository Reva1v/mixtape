# Quickstart: Mixtape MVP — запуск и проверка

## Требования

- Windows 10/11 x64, WebView2 Evergreen.
- Rust 1.97+ (MSVC), Node 22+, pnpm 11.
- Аккаунт YouTube Music; `cookies.txt` из инкогнито-сессии (если вход через окно недоступен).

## Сборка и запуск

```powershell
pwsh scripts/fetch-sidecars.ps1     # yt-dlp + deno в src-tauri/binaries
pnpm install
pnpm tauri dev                      # разработка
pnpm tauri build                    # релизная сборка (NSIS), замеры бюджетов — только на ней
cargo test --workspace              # тесты ядра (без сети)
cargo clippy --workspace -- -D warnings
pnpm -C ui check                    # svelte-check
```

## Замер бюджетов (релизная сборка, библиотека 20k треков)

| Бюджет | Как мерить | Порог |
|---|---|---|
| Старт | от запуска exe до первого кадра (лог `app_ready` с меткой времени) | ≤ 1,5 с |
| RAM | Private Working Set: `mixtape.exe` + все `msedgewebview2.exe` процесса, во время игры | ≤ 150 МБ |
| Поиск | `cargo bench`/тест на синтетической БД 20k + метка в логе команды | ≤ 50 мс |
| Переключение | лог: команда `next` → первый сэмпл в cpal-колбэке | ≤ 150 мс |
| Скролл | DevTools Performance, прокрутка списка 20k | 60 fps, без long tasks > 16 мс |
| Микс (первый звук) | лог `mix_start` → первый сэмпл | ≤ 2 с (локальный/в кэше), ≤ 5 с (иначе) |

### Результаты (2026-10-17, релизная сборка, синтетическая библиотека 20k треков)

Библиотека: `cargo run --release -p mixtape-library --example synth_library -- <dir> 20000`,
приложение запускается с `MIXTAPE_DATA_DIR=<dir>` (реальные данные не затрагиваются). Бинарь —
`cargo build --release -p mixtape --features tauri/custom-protocol` (без фичи он ищет dev-сервер).
